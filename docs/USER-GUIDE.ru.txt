PariPari Anti-HDR (JXR-SDR) — версия 1.7

ЗАПУСК
Откройте PariPari Anti-HDR 1.7.exe двойным щелчком. Установка и интернет не нужны.
Программа использует .NET Framework и JPEG XR-кодек Windows.
Собрана для Windows x64; проверена на этом компьютере.

ЯЗЫК
Первый запуск — на английском. Кнопка с флагом справа вверху переключает
English / Русский. Британский флаг — английский, российский — русский.
Флаг показывает текущий язык, подсказка — направление переключения. Перевод применяется сразу, без сброса файлов, настроек,
авторежима и масштаба. Выбор сохраняется для следующих запусков в
%LOCALAPPDATA%\PariPari Anti-HDR\language.txt.
Системные элементы диалогов Windows и сообщения самой ОС используют
язык Windows. Собственные заголовки и сообщения программы переведены.

КАК ПОЛЬЗОВАТЬСЯ
1. Над списком: лист с плюсом — добавить файлы; папка с плюсом —
   открыть папку; круговая стрелка — очистить список. Можно перетащить
   JXR-файлы или папку прямо в окно. Вложенные папки не сканируются.
2. Выберите кадр слева. Справа появится его SDR-превью.
3. В поле под списком файлов нажмите мышкой или двигайте точку с зажатой ЛКМ.
   Вверх — светлее, вниз — темнее; вправо — насыщеннее, влево — спокойнее.
   Диапазоны: яркость −5…+5 EV, насыщенность 0…130%.
   Цифры под полем можно редактировать вручную. Они синхронизированы
   с положением точки. Стрелки клавиатуры также двигают точку.
   Кнопка «Авто» рядом с яркостью включает автоматический режим для партии.
   Каждый кадр получает свою экспозицию и тональную кривую. Точку можно
   двигать после «Авто»: поправки запоминаются для этого кадра до конца сеанса.
   При переключении файлов они восстанавливаются.
   Подсвеченная кнопка означает, что «Авто» включено. Повторное нажатие
   выключает его и возвращает прежние ручные значения. Новое включение
   запускает свежий автоматический проход, сбрасывая прошлые автопоправки.
   Круговая стрелка выключает «Авто» и возвращает −3 EV и 50%.
4. Колесо мыши увеличивает область под курсором. Зажмите ЛКМ, чтобы
   переместить изображение. Двойной щелчок вписывает изображение в окно.
   Кнопка с четырьмя стрелками переключает 1:1 и вписывание в окно.
   Масштаб и положение сохраняются при изменении настроек цвета.
   Детали просматриваются из полноразмерного изображения.
5. Нажмите «Сохранить выбранный» или «Сохранить все». PNG сразу
   сохраняется рядом со своим оригиналом, без диалога выбора папки.
   При включённом «Авто» каждый файл обрабатывается со своими настройками;
   ещё не просмотренные кадры анализируются при сохранении. Ваши ручные
   поправки к автонастройке учитываются. При выключенном «Авто» для всей
   партии применяются текущие яркость и насыщенность.
   Если исходники из разных папок, каждый PNG остаётся в своей папке.
6. «Показать PNG в папке» выделяет результат выбранного файла
   в Проводнике; если для него результата ещё нет — открывает последнюю
   папку сохранения. В списке появляется отметка «PNG сохранён».

Delete в списке — убрать выбранный файл из списка. Файл на диске
и сохранённый PNG остаются на месте. При обработке Delete отключён.
«Открыть папку» использует современный системный диалог Windows
с адресной строкой, поиском и быстрым доступом.

Горячие клавиши: Ctrl+O — добавить; Ctrl+S — сохранить выбранный;
Ctrl+Shift+S — сохранить все.

Результат: исходное разрешение, PNG RGB 8 бит/канал, sRGB + gAMA.
К имени добавляется _SDR. При совпадении имён добавляется номер.
Оригиналы и существующие PNG не перезаписываются.
«Остановить» завершает текущий файл и отменяет оставшуюся очередь.

О ЦВЕТЕ
Вход: HDR JXR/WDP/HDP, которые декодер Windows предоставляет как
float RGB/RGBA scRGB. Обычные SDR PNG и прочие HDR-форматы не поддерживаются.
Ограничение размера: 45 мегапикселей; большие файлы требуют много памяти.

В ручном режиме используется кривая Reinhard по линейной яркости, затем
сжатие цвета к нейтральной оси для помещения в охват sRGB, затем
передаточная функция sRGB. Начальный уровень белого — 203 нит
(scRGB 1 = 80 нит). Отрицательные RGB не обрезаются до преобразования.
Выход непрозрачный; прозрачность входа компонуется на чёрном фоне.

В режиме «Авто» анализируется равномерная выборка до 512×512 пикселей
из исходного линейного HDR. Практически чёрные пиксели не участвуют
в статистике. Медиана даёт частичную адаптацию яркости, 90-й процентиль
ограничивает засветку крупных светлых областей, 99-й управляет плавным
сжатием светов. Единичный экстремальный пиксель не задаёт белую точку.
Используется обобщённая кривая Reinhard x/(1+x^p)^(1/p), p=0.65…2.4.
Автоэкспозиция ограничена −5…+1.5 EV; вручную доступно −5…+5 EV.
Параметры — эвристика для стартового результата, а не восстановление
авторского замысла. Чёрный остаётся чёрным, подъём ночных сцен ограничен.
«Авто» начинает с насыщенности 100%; выходящие за sRGB цвета сжимаются
к нейтральной оси. Глобальная насыщенность остаётся ручной поправкой:
алгоритм не угадывает желаемую насыщенность травы, кожи или эффектов.
Превью и экспорт используют одинаковые настройки и одну функцию цвета.

Это практическое SDR-представление HDR-кадра, а не точная копия
яркости и цветового охвата HDR-монитора. Внешний вид зависит от
исходного кадра и выбранной экспозиции. Уже утраченные в исходнике
детали восстановить невозможно. Генеративный ИИ не используется.

ИСХОДНИКИ
Source\Program.cs — преобразование и окно; Source\Widgets.cs —
иконки, двумерное поле настройки и просмотр изображения.
Source\AutoTone.cs — анализ HDR и адаптивная тональная кривая.
Source\Localization.cs — английский/русский и сохранение выбора языка.
Source\Theme.cs — оформление панелей, кнопок, флагов и баннера.
Source\Assets\Banner.png — исходный баннер, встроенный в EXE.
Для запуска достаточно EXE, отдельная картинка рядом с ним не требуется.
Source\build.ps1 — сборка
штатным компилятором .NET Framework Windows, без загрузки зависимостей.

Для автоматизации:
"PariPari Anti-HDR 1.7.exe" --convert "input.jxr" "output-folder" 0 100
Последние значения: EV и насыщенность в процентах. Для начальных значений интерфейса
укажите -3 50. Режим командной строки сохраняет прежние значения
по умолчанию 0 100 для совместимости.
Автоматическое преобразование:
"PariPari Anti-HDR 1.7.exe" --convert-auto "input.jxr" "output-folder"
Код завершения: 0 — успех, 1 — ошибка. GUI-сборка не имеет консоли.
