# Version history

## 1.7 — First public release

- Custom banner and cyan/teal interface with angled panels and buttons.
- Flag button for instant English/Russian switching; the choice is remembered.
- Per-image Auto exposure and adaptive highlight compression.
- Brightness/saturation pad with manual fine-tuning.
- Full-resolution preview with pointer-centered zoom and drag-to-pan.
- Single-image and batch export to SDR PNG beside each original.
- Non-overwriting output names and modern Windows folder picker.
- Command-line conversion and source build script included.

## Development iterations

- **1.6:** English by default, Russian option, persistent language selection.
- **1.5:** Automatic per-image adjustments and batch Auto processing.
- **1.4:** Two-dimensional adjustment pad and refined controls.
- **1.3:** Minimal interface, preview zoom and panning.
- **1.2:** PariPari branding, Delete-to-remove and modern folder picker.
- **1.1:** Friendlier interface and saving next to the original.
- **1.0:** Initial HDR JXR-to-SDR PNG conversion core.
